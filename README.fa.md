# jobreferrer: ربات کاریابی برای مهاجرت

**رزومه بدهید؛ موقعیت‌های شغلی خارج از کشور با اسپانسر ویزا و کمک جابه‌جایی، پروژه‌های فریلنسری، نامه آماده برای متقاعد کردن هر کارفرما و برنامه قدم‌به‌قدم مهاجرت بگیرید.**

## چه کار می‌کند؟

۱. **رزومه را با هر فرمت رایجی می‌خواند**: PDF، Word (DOCX و DOC قدیمی)، ODT، RTF، HTML، متن، JSON Resume و حتی عکس یا اسکن رزومه (JPG/PNG، PDF اسکن‌شده). رزومه **فارسی** هم پشتیبانی می‌شود (اعداد فارسی، تاریخ شمسی و عنوان‌های شغلی فارسی). بدون کلید API، پارسر داخلی عنوان شغلی، مهارت‌ها، سابقه، زبان‌ها، مدرک و دستاوردها را استخراج می‌کند؛ برای خواندن عکس و اسکن، کلید Claude لازم است.

۲. **در ۱۴ منبع کاریابی همزمان جستجو می‌کند** و برای بیش از ۴۰ سایت دیگر (لینکدین، Indeed در ۳۱ کشور، StepStone، XING، SEEK، Bayt، Relocate.me، Jaabz، EURES و…) لینک جستجوی آماده می‌سازد.

۳. **آگهی‌ها را مخصوص کسی که می‌خواهد مهاجرت کند امتیاز می‌دهد**: تطابق مهارت و عنوان، اسپانسر ویزا، کمک جابه‌جایی، کشور هدف، زبان محلی لازم، دورکاری‌هایی که فقط برای آمریکا هستند، و تازگی آگهی.

۴. **بخش مهاجرتی را بررسی می‌کند**:
   - کارفرما در فهرست رسمی اسپانسرهای ویزای انگلستان و هلند ثبت شده یا نه
   - حقوق آگهی از حداقل حقوق ویزای ۲۰۲۶ بیشتر است یا نه (بلوکارت اروپا، kennismigrant هلند، Skilled Worker انگلستان، Critical Skills ایرلند، ویزای کار سوئد)

۵. **برای بهترین موقعیت‌ها متن آماده می‌نویسد**: نامه به کارفرما (Cover Letter)، پیام کوتاه به ریکروتر، موضوع ایمیل، کلیدواژه‌های جاافتاده، راهنمای گرفتن همان موقعیت و سوالات احتمالی مصاحبه.

۶. **پروژه‌های فریلنسری مرتبط را با پروپوزال آماده لیست می‌کند** و پلتفرم‌های مناسب (از جمله پونیشا و کارلنسر) را معرفی می‌کند.

۷. **استراتژی شخصی شما را می‌سازد**:
   - بهترین کشورها و مسیرهای ویزا برای پروفایل شما
   - اصلاحات رزومه و لینکدین
   - نرخ پیشنهادی فریلنسری
   - برنامه ۴ هفته‌ای
   - هشدار کلاهبرداری و هشدارهای مخصوص ملیت، مثلاً برای پاسپورت ایرانی: محدودیت ورود به آمریکا، بررسی امنیتی طولانی‌تر، سفارت‌های جایگزین و محدودیت پلتفرم‌ها

۸. **خروجی** را به این شکل‌ها می‌دهد:
   - گزارش HTML فارسی (راست‌به‌چپ) یا انگلیسی با دکمه کپی و فیلتر
   - Markdown و JSON
   - ربات تلگرام
   - صفحه وب
   - گزارش روزانه تلگرامی از طریق GitHub Actions (بدون نیاز به سرور)

## شروع سریع

به Node.js نسخه ۲۰ یا بالاتر نیاز دارید.

<div dir="ltr">

```bash
git clone https://github.com/masterkasra/jobreferrer.git
cd jobreferrer
npm install

npm run demo   # گزارش نمونه با داده آزمایشی، بدون اینترنت و کلید

node bin/jobreferrer.js resume.pdf --countries DE,NL,GB,IE,CA --nationality IR --lang fa
```

</div>

برای نامه‌ها و استراتژی کاملاً شخصی‌سازی‌شده، فایل `.env.example` را به `.env` کپی کنید و `ANTHROPIC_API_KEY` را بگذارید. کلیدهای رایگان Adzuna، Jooble و Reed هم پوشش آگهی‌ها را بیشتر می‌کنند. بدون هیچ کلیدی هم ربات کار می‌کند.

## ربات تلگرام

۱. از [@BotFather](https://t.me/BotFather) یک ربات بسازید و توکن را در `.env` بگذارید (`TELEGRAM_BOT_TOKEN`).

۲. دستور `npm run bot` را اجرا کنید، یا با داکر: `docker build -t jobreferrer . && docker run -d --env-file .env -v jr:/app/.cache jobreferrer`.

۳. رزومه را برای ربات بفرستید. ربات موارد زیر را برمی‌گرداند:
   - لیست موقعیت‌ها
   - یک دکمه «✉️» برای هر موقعیت که نامه و پیام آماده را نشان می‌دهد
   - فایل گزارش کامل

دستورها: `/countries DE NL GB`، `/nationality IR`، `/title …`، `/lang fa|en`، `/jobs`، `/daily` (گزارش روزانه آگهی‌های جدید)، `/settings`، `/forget` (حذف اطلاعات).

با `TELEGRAM_ALLOWED_USERS` می‌توانید استفاده از ربات را به آیدی‌های مشخص محدود کنید.

## گزارش روزانه رایگان با GitHub Actions

ورک‌فلو [`daily-digest`](.github/workflows/daily-digest.yml) هر روز صبح اجرا می‌شود و فقط آگهی‌هایی را که قبلاً ندیده‌اید به تلگرام می‌فرستد. برای راه‌اندازی:

۱. در مخزن به Settings ← Secrets and variables ← Actions بروید.

۲. این Secretها را اضافه کنید:
   - `TELEGRAM_BOT_TOKEN` و `TELEGRAM_CHAT_ID`
   - `RESUME_B64` (خروجی دستور `base64 -w0 resume.pdf`) یا `RESUME_TEXT`
   - در صورت تمایل `ANTHROPIC_API_KEY`

۳. این Variableها را اضافه کنید: `DIGEST_ENABLED=true`، `TARGET_COUNTRIES`، `NATIONALITY=IR`، `REPORT_LANG=fa`، `RESUME_NAME`.

اگر رزومه را در مخزن نگه می‌دارید، مخزن را خصوصی (Private) کنید.

## صفحه وب

دستور `npm run web` را اجرا کنید و به <span dir="ltr">http://localhost:3000</span> بروید. رزومه را آپلود کنید، کشورها را انتخاب کنید و گزارش را در مرورگر بگیرید.

## منابع آگهی

- **رایگان:** Arbeitnow (آلمان/اروپا با برچسب اسپانسر ویزا)، سایت کاریابی دولت آلمان، Remotive، Remote OK، Jobicy، Himalayas، Working Nomads، We Work Remotely، The Muse، HN Who is Hiring، Freelancer.com
- **با کلید رایگان:** Adzuna (۱۹ کشور)، Jooble (بیش از ۷۰ کشور)، Reed (انگلستان)

## تفاوت با رقبا

خلاصه [تحلیل کامل](docs/competitors.md):
- ابزارهایی مثل Jobright، Teal، Huntr و LazyApply یا روی آمریکا تمرکز دارند، یا فقط ردیابی می‌کنند، یا انبوه و بدون شخصی‌سازی اپلای می‌کنند.
- ابزارهای مخصوص ویزا (Migrate Mate، JobMetasearch، Relocate.me) پولی، تک‌کشوری یا فقط انگلیسی هستند.
- jobreferrer رایگان و متن‌باز است و فارسی را پشتیبانی می‌کند.
- اطلاعات ویزا و حداقل حقوق، بررسی فهرست اسپانسرها، تشخیص کلاهبرداری، هشدارهای مخصوص ملیت و مسیر موازی فریلنسری را کنار هر آگهی می‌آورد.

قوانین مهاجرت و حداقل حقوق‌ها تغییر می‌کنند. ارقام در سپتامبر ۲۰۲۶ بررسی شده‌اند و گزارش همیشه لینک منبع رسمی را می‌دهد. این ابزار راهنماست، نه مشاوره حقوقی.
